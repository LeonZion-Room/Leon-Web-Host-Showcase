开发者模式

管理员登录 → 管理后台 →「开发者模式」标签页。

功能概述

开发者模式提供任意 C3 HTTP 接口调试能力，可在浏览器中直接调用 C3 网关（19002），无需后端介入。

操作步骤

选择接口

从下拉菜单选择接口，系统自动填充最近一次调用记录的参数。

支持的接口：

类别 接口
认证 获取 Token
账户管理 获取员工列表、获取员工详情、创建/修改员工、创建/修改人脸库、获取员工详情（含 Base64 人脸照）
权限管理 获取权限列表、添加/修改/删除/撤销权限、按 Mac 添加/修改/撤销权限、查询员工在某设备/门禁上的权限
二维码 获取员工开门二维码
人脸设备 获取员工下发列表、下发员工、获取人脸照片、添加/修改/删除人脸库、人脸设备基本控制
通用 获取全部门禁点位、初始化 C3 接口（19001）

填写参数

  • 选择 GET/POST
  • 输入请求体
  • 参数输入框支持格式化对齐
  • 默认选中「启用」（传 token）

执行与结果

  • 点击「执行请求」
  • 下方显示：请求头、请求体（格式化）、响应内容（格式化）、耗时
  • 历史按钮：查看该接口的调用历史

C3 请求基础参数

参数 值
网关地址 http://192.168.101.7:19002
API 路径 /api/AccessInterface
Header Content-Type: application/json
认证 传 token 时携带 Bearer token

注意事项

  • 所有参数使用中文字段名，系统自动转换为英文字段名
  • 失败操作自动回滚
  • 此功能仅超管 Leon 可使用
