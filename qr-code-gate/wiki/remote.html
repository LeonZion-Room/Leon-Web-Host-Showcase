远程开门

管理员登录 → 管理后台 →「门禁控制」标签页。

门禁规模

指标 数值
门禁点位 404 个（启用 387 个）
覆盖范围 E 座东区/西区通道、各栋消防梯、电梯厅、大堂门
开门方式 按门名称（doorName）直接远程开门

单个开门

  1. 登录后进「管理后台」→ 点「门禁控制」标签页
  2. 在门禁列表中搜索或定位目标门禁
  3. 点击该行「🔴 开门」按钮
  4. 开门结果实时显示在下方，成功/失败一目了然

一键打开全部门

  1. 点击「🚪 一键打开全部门」按钮
  2. 系统后台并发按门名称逐个开门
  3. 执行过程实时显示进度（已完成 X/Y · 成功 Z）与逐门结果表格

注意：一键全开只有超管 Leon 能操作。

C3 开门策略

flowchart TD
    A[点击开门] --> B{AccessInterface 签名版}
    B -->|成功| C[开门成功]
    B -->|失败| D{C3WebApi 无签名版}
    D -->|成功| C
    D -->|失败| E[开门失败]
  • 优先走 AccessInterface（19001）按门名称签名开门
  • 失败回退 C3WebApi（19002）无签名版
  • 两种都用 doorName 定位，不用选设备 Mac

同步门禁

点击「🔄 同步门禁」从 C3 拉取全部门禁点位。

同步后本地缓存 data/doors.json，包含门禁 ID、名称、设备 Mac、启用状态等。

注意事项

  • 远程开门只针对普通门锁点位
  • 人脸设备不能远程开——人脸设备是靠提前下发人脸权限、现场刷脸进的
  • 开门按钮只有超管 Leon 看得到、用得了
