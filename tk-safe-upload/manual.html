Overview

这是什么平台？

TK-Safe-UpLoad 是大鹏投控集团用来管理安全生产工作的一站式智能平台。简单说，就是把以前用纸笔、微信群、Excel表格做的安全工作，全部搬到电脑和手机上来做。

📷 随手拍上报 核心功能

发现安全隐患时，用手机拍照上报。系统自动生成隐患工单，由安全管理员分派责任单位限期整改。

隐患随手拍上报

填写信息、上传照片、一键提交

操作步骤

  1. 点击首页的"📷 随手拍"图标
  2. 填写隐患标题（必填）和描述
  3. 选择隐患分级：一般/较大/重大
  4. 选择所属单位和绑定点位
  5. 上传现场照片（最多6张，点击可删除）
  6. 点击"提交上报"按钮

隐患治理流程

  1. 分派工单：选择责任人、责任单位、设置整改期限
  2. 提交整改：责任人填写整改说明、上传佐证照片
  3. 复核销号：管理员审核整改结果，通过则销号，退回则继续整改
  4. 挂牌督办：重大隐患可标记为挂牌督办或强制停工

FAQ

常见问题与解答

遇到问题不要慌，这里有您需要的答案。

Q1: 登录后看不到PC管理后台入口？

原因：您的角色没有PC后台访问权限。

解决：联系管理员，在"用户管理"中将您的角色调整为"公司管理员"或"安全员"。

Q2: 手机端照片上传失败？

原因：照片格式不支持、文件太大、网络不稳定。

解决：检查照片格式（支持jpg/png/gif/bmp/webp），压缩照片大小，重试上传。

Q3: 如何修改密码？

步骤：进入"个人中心"（👤）→ 点击"修改登录密码" → 输入旧密码和新密码 → 点击"保存新密码"。

Q4: 隐患上报后如何查看处理进度？

步骤：进入"个人中心"（👤）→ 查看"我的上报隐患" → 点击隐患标题查看详情 → 查看治理流转记录。

Q5: 如何导出数据？

步骤（仅管理员）：进入PC管理后台 → 进入对应模块 → 点击"导出"按钮 → 选择导出格式（Excel/PDF）→ 下载文件。
