Step 0

测试准备

磨刀不误砍柴工。先备好地址、账号和测试数据标记规范。

项值
测试站（内网）http://192.168.11.70:5112
管理员admin / admin123（全部权限）
安全员inspector / inspector123（无用户管理权限，正好测 403）
普通员工staff / staff123
⚠️ 测试数据标记：所有新建的测试数据，标题/名称一律加前缀 【点检】（如 【点检】配电房隐患）。这样最后收尾时能一键认出并删干净，不污染生产数据。看到旧的 测试/冒烟 数据不要动，那是历史遗留。
💡 建议开两个浏览器窗口：左边手机端（按 F12 切手机模式），右边 PC 后台。这样随手拍提交后，右边立刻能看到工单，绑定关系一目了然。
Step 1

登录页点检

地址：http://192.168.11.70:5112/login —— 门卫，拦住坏人、放行自己人。

登录页：用户名 + 密码 + 登录按钮
1-1

空密码被拒 —— 空手不能进门

点哪里用户名填 admin，密码留空，点「登录」
看到什么弹出“请输入账号和密码”，停在登录页
数据验证后台 logs 表不应新增 login 成功记录
1-2

错密码被拒并留痕 —— 小偷踩点要记下来

点哪里用户名 admin，密码随便输错，点「登录」
看到什么提示用户名或密码错误；连输 5 次会被锁 15 分钟（429）
数据验证PC后台 → 操作日志，能查到一条 login_fail（action 列），detail 含用户名
1-3

正确登录进工作台 —— 主流程

点哪里admin / admin123 点「登录」
看到什么跳到统一工作台，右上角显示“系统管理员”；F12 → Application → Cookies 有 tk_safe_session
数据验证操作日志新增一条 login / auth，user=系统管理员
Step 2

统一工作台点检

地址：/portal —— 总大厅，三扇门通三端，头顶四个数字是全站缩影。

统一工作台：数据面板 + 三端入口
2-1

四个数字互相咬合 —— 数字不是摆设

点哪里看顶部：隐患总数 / 逾期未整改 / 我的待办 / 我的上报
看到什么四个数字都有值；点数字能跳到对应列表页
数据验证隐患总数 ＝ PC后台隐患治理列表总数；逾期数 ＝ 列表里 deadline 超期且未销号的数量（抽 1 条点进去看 deadline）。待办数 ＝ 任务页待办数
2-2

三端入口各就各位 —— 三扇门都要能推开

点哪里依次点「打开移动端」「PC管理后台」「可视化大屏」
看到什么分别进入 /m、/admin、/screen，无 404/500；staff 账号看不到 PC 后台入口（无权限）
数据验证移动端首页的隐患总数与工作台一致（同一张 hazards 表）
Step 3

移动端逐页点检

F12 切手机模式（390px）。员工每天用的 9 个页面，一个一个过。

移动端首页：快捷操作九宫格 + 底部 5 导航
3-1

随手拍：提交→后台立刻有工单 —— 核心链路，必须通

点哪里首页点「📷 随手拍」→ 标题填 【点检】配电房电缆裸露 → 级别选一般 → 单位/点位任选 → 传 1 张照片 → 点「提交上报」
看到什么提示“提交成功，已生成隐患工单”；照片可点放大、可删；不填标题点提交会被拦下
数据验证右边 PC后台 → 隐患治理，筛选“待分派”，第一条就是它（标题/照片/上报人一致）；hazards.status=pending 且多一条 hazard_flow(action=create)。记下它的 id，后面 3-3、5-1 要用
3-2

巡查打卡：签到留痕 —— 到没到过现场，记录说了算

点哪里底部「📍 巡查」→ 选一个进行中的计划 → 点「开始巡查签到」→ 选点位 → 现场记录填 【点检】正常 → 状态选正常 → 点「确认签到」
看到什么提示签到成功，该点位变“已签到”；选“发现异常”时会提示去随手拍上报
数据验证PC后台 → 巡查记录多一条（plan_id/point_name/记录一致）；个人中心 → 我的打卡数 +1
3-3

任务：提交整改→待复核 —— 闭环的前半段

点哪里先去 PC后台把 3-1 那条隐患分派给 staff（责任人写 staff）。再用 staff 登录手机端 →「📋 任务」→ 点该整改任务 →「📷 提交整改」→ 说明填 【点检】已包扎 → 传整改后照片 →「提交并等待复核」
看到什么任务从待办消失（或变已提交）；不传照片也能提交，但有照片更合规
数据验证PC后台该隐患状态变为“待复核”，hazard_flow 多一条 action=rectify，rectify_note 一致
3-4

举报：匿名也收得到 —— 给不敢具名的人留条路

点哪里首页「🚨 举报」→ 标题 【点检】匿名举报测试 → 勾选匿名 → 提交
看到什么提交成功；个人中心“我的上报”里看不到它（匿名的代价）
数据验证PC后台隐患列表能找到它，且 anonymous=1、reporter 为空；violation_reports 表多一条
3-5

培训：看完→进度→证书 —— 学没学完，进度条说了算

点哪里首页「🎓 培训」→ 进一门课 → 播放视频（试试倍速/全屏/空格暂停）→ 点「✓ 标记完成」→ 试着加一条笔记再删掉
看到什么课时变“已完成”，课程进度条上涨；笔记能增能删；全部课时完成后出现证书
数据验证training_lesson_progress 有你的 user_id 记录；training_notes 增删对应；training_certificates 在全完成时多一条
3-6

资料：三板块+搜索 —— 应急时找得到东西

点哪里首页「📚 资料」→ 三个板块各点一篇 → 顶部搜索框搜一个关键词
看到什么应急预案/风险管控卡/制度文档都能打开；搜索结果即时过滤；风险卡颜色与级别对应（红重大/橙较大/黄一般/蓝低）
数据验证预案来自 emergency_plans，管控卡来自 risk_points（level 决定颜色）
3-7

待办：五类预警 —— 该催办的一个别漏

点哪里底部「⏰ 待办」→ 五类逐个点开看明细
看到什么逾期隐患/设备到期/证件到期/复核到期/物资提醒五类齐全；点条目能跳到对应处理页
数据验证逾期数与工作台逾期数一致（同一次查询逻辑）；设备到期来自 equipment.next_inspection
3-8

个人中心：改密+改资料 —— 自己的账号自己管

点哪里底部「👤」→「修改登录密码」（先输错旧密码一次，再正确修改，改完退出重登）→「更新姓名/手机号」改个手机号再改回来
看到什么旧密码错误被拒；新密码可登录；手机号即时更新；“我的上报/打卡/培训”三个数与前面操作对得上
数据验证users 表对应行 phone/password 变化；logs 有改密记录
Step 4

PC后台逐模块点检

用 admin 登录，地址 /admin。左菜单自上而下，一个模块不落。

仪表盘：隐患统计 + 风险分布 + 整改率排名，三组数字是全站数据的镜子
4-1

仪表盘：三组数字与明细一致

点哪里看隐患统计 / 风险分布 / 各单位整改率排名
看到什么三组数字非空；整改率条形与百分比对应
数据验证隐患总数＝隐患治理列表总数；风险分布＝双重预防各级别点数之和；点某单位名，跳过去逐条数，算出的整改率与展示一致
4-2

隐患治理：走完分派→复核→销号闭环 —— 后台最重要的一条链

点哪里① 待分派里找到 3-1 的【点检】隐患 → 选责任人/单位/期限 →「分派工单」②（3-3 已提交整改后）待复核里打开它 → 看整改说明+照片 → 填复核意见 →「复核销号」③ 另找一条点「退回整改」再看它回到整改中 ④ 对一条重大隐患点「重大挂牌/停工」再取消
看到什么状态依次流转 待分派→整改中→待复核→已销号；退回能打回；挂牌有醒目标记；筛选（状态/级别/关键字）+「查看详情」都正常
数据验证hazards.status 跟着变；hazard_flow 按顺序多出 assign→rectify→review/close；tasks 同步生成/关闭；销号后工作台隐患总数-1、待办数变化
隐患治理：工单列表、筛选、分派、复核、销号全在这里
4-3

基础台账：增→改→删走一遍 —— 每个“+新增”按钮都要活

点哪里经营主体/特种设备/人员/相关方/应急物资五个页：各点「+新增」建一条【点检】数据 → 点「编辑」改名 → 点「删除」删掉；物资页额外点「入库」「出库」「流水」「盘点」
看到什么新增即时出现在列表；编辑即时生效；删除需二次确认；出库超库存被拒绝；盘点更新 last_inventory 时间
数据验证对应表 organizations / equipment / personnel / related_parties / materials(+material_io) 增删改各对一条；出入库在 material_io 留两条（in/out），materials.quantity 加减正确
4-4

双重预防：新增风险点+复核

点哪里「+新增风险点」→ 名称 【点检】配电房触电风险 → 级别选红 → 填管控措施/责任人/复核周期 → 保存 → 点「复核」填结果 → 再「编辑」改级别 → 「删除」
看到什么列表颜色随级别变（红/橙/黄/蓝）；复核后下次复核日期顺延；删除需确认
数据验证risk_points 增删各一；risk_reviews 多一条；仪表盘风险分布红数 +1 再 -1
4-5

专项整治：新增+归档记录

点哪里「+新增专项行动」（模板选消防，标题 【点检】消防专项）→ 点「归档检查记录」填检查项 → 保存 → 删除
看到什么行动出现在列表；检查记录可展开看；删除连记录一起清
数据验证special_actions 增删各一，关联记录同步
4-6

安全培训：课程+课时全链

点哪里「+新增课程」（标题 【点检】消防课）→「添加视频」挂课时 → 用 staff 账号去手机端学完 → 回来看学时统计 → 删除课程（连带课时/记录一起清）
看到什么课程页有课时数；删除课程弹确认并级联清理；手机端 3-5 的进度在这里能看到
数据验证training_courses/lessons/records 联动；删除后三表无残留（重点查）
4-7

应急管理：预案+演练+通讯录

点哪里三个 Tab 各「+新增」一条【点检】数据 → 各「编辑」改一次 → 各「删除」
看到什么手机端 3-6 资料页同步出现新预案（发布即同步）；删除后手机端同步消失
数据验证emergency_plans / drill_records / contacts 增删各一
4-8

作业许可：申请→两级审批→销项 —— 最长的审批链

点哪里「+新建作业许可」（标题 【点检】动火作业，提交申请）→「一级审批」通过 →「二级审批」通过 →「完工销项」
看到什么状态步步推进：待审批→一级通过→二级通过→已销项；驳回能打回（可另测一次驳回）
数据验证work_permits.status 跟着走；每步审批人和时间落库
4-9

报表：导出真能下载

点哪里统计报表页看趋势图 → 点「⬇ 导出 Excel」「导出 PDF」→ 下载打开看
看到什么文件正常下载、能打开、中文不乱码、行数与列表一致
数据验证Excel 行数 ＝ 当前筛选条件下隐患数；PDF 含统计数字
4-10

用户管理：增改删 + 403 —— 权限的试金石

点哪里「+新增用户」（用户名 dianjian，角色 staff）→ 用它登录一次 → 改它为 inspector → 删除；再用 inspector 账号访问「用户管理」页
看到什么新用户可登录；改角色即时生效；删除后登录提示账号不存在；inspector 进用户管理看到人性化 403 页（不是空白）
数据验证users 增改删各一，最终无 dianjian 残留
4-11

日志与设置：有痕可查、配置即时生效

点哪里操作日志页按关键字搜 【点检】/按模块筛 → 系统设置页改一条配置保存 → 点「发送测试」
看到什么今天的点检操作在日志里都能搜到；配置保存后刷新还在；无效 webhook 发送不报错（降级记日志）
数据验证logs 可按关键字/模块命中；site_settings 值已更新
Step 5

大屏点检

地址：/screen —— 免登录，给领导看的门面，数字必须和后台一致。

可视化调度大屏：隐患统计 + 风险分布 + 趋势 + 整改率
5-1

大屏数字＝后台数字 —— 门面不能撒谎

点哪里新开无痕窗口打开 /screen（验证免登录）→ 逐项抄下数字
看到什么页面自适应、无需登录、图表正常渲染、无 500
数据验证隐患总数/逾期/重大/整改率 ＝ 仪表盘 4-1 的数；风险分布 ＝ 4-4 的数。做完 4-2 销号后刷新大屏，数字应跟着变（验证实时性）。本页曾因 longitude!='' 在 PG 报错 500，已修——若再现 500 即回归失败
Step 6

前台一点、后台一查，表名就是证据。抽查时直接用这张表。

Step 7

收尾清理

考完试擦黑板。所有 【点检】 数据必须删干净，生产库干干净净交回去。

7-1

删光【点检】数据并复核

点哪里PC后台各列表搜关键字 【点检】 → 逐条删除；用户页删 dianjian；隐患页确认销号的那条也删（或保留归档，请示负责人）
看到什么全站搜 【点检】 零结果；工作台四个数字回到点检前（对照开始时拍的照）
数据验证各表无 【点检】 残留；logs 保留（审计不删）；旧的 测试/冒烟 历史数据不动
⚠️ 别删错：只删自己建的 【点检】 和 dianjian。历史遗留的 测试/冒烟 数据是生产库沉积问题，另立数据治理任务处理，本次不动。
