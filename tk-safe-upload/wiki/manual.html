一、系统简介

TK-Safe-UpLoad 是一个面向企业的安全生产管理平台，主要用于：

  • 隐患排查治理：发现安全隐患 → 上报 → 整改 → 复核 → 销号（闭环管理）
  • 安全培训：在线学习安全知识、观看培训视频、获得证书
  • 巡查打卡：定期巡查工作场所，记录检查情况
  • 应急管理：管理应急预案、演练记录、通讯录
  • 数据分析：统计报表、趋势分析、可视化大屏

简单来说，这个系统帮助企业和员工做好安全生产工作，防止事故发生。

5.3 随手拍上报隐患

场景：发现安全隐患时，用手机拍照上报。

图：隐患随手拍上报页面

操作步骤：

1. 点击首页的"📷 随手拍"图标
2. 填写隐患信息：
   - 隐患标题（必填）：简要描述隐患
   - 隐患描述：详细描述情况
   - 隐患分级：选择一般/较大/重大
   - 所属单位：选择责任单位
   - 绑定点位：选择风险点位
3. 上传照片：
   - 点击"+"按钮选择照片
   - 最多上传6张
   - 点击已选照片可以删除
4. 点击"提交上报"按钮
5. 看到"提交成功！已生成隐患工单"提示

隐患分级说明：

级别 颜色 说明
一般隐患 🟡 黄色 影响较小，可限期整改
较大隐患 🟠 橙色 影响较大，需优先处理
重大隐患 🔴 红色 影响严重，需立即处理

💡 提示：上报后系统会自动生成隐患工单，由安全管理员分派责任单位限期整改。

5.4 巡查打卡

场景：按照巡查计划，到指定地点进行安全检查。

图：巡查打卡页面

操作步骤：

1. 点击底部导航的"📍 巡查"
2. 查看当前进行中的巡查计划
3. 选择一个计划，点击"开始巡查签到"
4. 选择签到点位
5. 填写现场记录
6. 选择现场状态（正常/发现异常）
7. 可选：上传现场照片
8. 点击"确认签到"

巡查计划类型：

类型 说明
日常巡查 每日例行安全检查
专项检查 针对特定区域或设备的检查
节假日督查 节假日期间的安全督查

6.3 隐患治理

这是后台最重要的功能模块。

图：隐患治理页面 - 工单列表与筛选

6.3.1 查看隐患列表

1. 点击左侧菜单"🚨 隐患治理"
2. 查看所有隐患工单
3. 使用筛选条件：
   - 按状态筛选：待分派/整改中/待复核/已销号
   - 按级别筛选：重大/较大/一般
   - 关键字搜索：标题/描述/上报人/责任人
4. 点击"查看详情"查看隐患详情

6.3.2 分派工单

1. 找到状态为"待分派"的隐患
2. 选择责任人
3. 选择责任单位
4. 设置整改期限（天数）
5. 点击"分派工单"

6.3.3 复核销号

1. 找到状态为"待复核"的隐患
2. 查看整改说明和佐证照片
3. 填写复核意见
4. 点击"复核销号"或"退回整改"

6.3.4 挂牌督办

对于重大隐患，可以标记为"挂牌督办"或"强制停工"。

1. 找到需要督办的隐患
2. 点击"重大挂牌/停工"
3. 确认操作

八、常见问题与解答

Q1: 登录后看不到PC管理后台入口？

原因：您的角色没有PC后台访问权限。

解决：联系管理员，在"用户管理"中将您的角色调整为"公司管理员"或"安全员"。

Q2: 手机端照片上传失败？

原因： - 照片格式不支持（只支持 jpg/png/gif/bmp/webp） - 照片文件太大 - 网络连接不稳定

解决： - 检查照片格式 - 压缩照片大小 - 重试上传

Q3: 如何修改密码？

步骤： 1. 进入"个人中心"（👤） 2. 点击"修改登录密码" 3. 输入旧密码和新密码 4. 点击"保存新密码"

Q4: 隐患上报后如何查看处理进度？

步骤： 1. 进入"个人中心"（👤） 2. 查看"我的上报隐患" 3. 点击隐患标题查看详情 4. 查看治理流转记录

Q5: 如何导出数据？

步骤（仅管理员）： 1. 进入PC管理后台 2. 进入对应模块（如隐患治理） 3. 点击"导出"按钮 4. 选择导出格式（Excel/PDF） 5. 下载文件
