用户管理

用户列表

  • 显示所有系统用户
  • 显示用户名、姓名、角色、所属单位、状态

新增用户

  1. 点击「+ 新增」按钮
  2. 填写用户信息：
  3. 用户名（必填）：登录账号
  4. 姓名（必填）：真实姓名
  5. 手机号：联系电话
  6. 角色（必填）：选择角色类型
  7. 所属单位（必填）：选择经营主体
  8. 点击「保存」

编辑用户

  • 点击行内「编辑」按钮
  • 修改用户信息
  • 保存修改

用户状态管理

  • 启用：允许用户登录
  • 禁用：禁止用户登录

密码管理

  • 重置用户密码
  • 用户可自行修改密码

消息模板配置

模板列表

  • 显示所有消息模板
  • 显示模板名称、通道、内容

新增模板

  1. 点击「+ 新增」按钮
  2. 填写模板信息：
  3. 模板名称：模板标识
  4. 通知通道：微信服务通知/短信
  5. 模板内容：支持变量替换
  6. 点击「保存」

支持的变量

变量 说明
{title} 消息标题
{name} 用户姓名
{date} 日期时间

预警规则配置

规则列表

  • 显示所有预警规则
  • 显示规则名称、阈值类型、提前天数、通道

新增规则

  1. 点击「+ 新增」按钮
  2. 填写规则信息：
  3. 规则名称
  4. 阈值类型：选择预警类型
  5. 提前天数：提前多少天预警
  6. 通知通道：选择通知方式
  7. 点击「保存」

支持的预警类型

类型 说明
隐患整改逾期 隐患超过整改期限
设备年检到期 特种设备年检日期临近
证件到期 人员资质证书即将过期
风险复核到期 风险点需要重新评估
维保到期 设备维保日期临近

推送通道配置

微信推送

  • 配置微信服务通知的 Webhook URL
  • 用于推送微信模板消息

短信推送

  • 配置短信网关地址
  • 用于发送短信通知

保存配置

  • 修改后点击「保存配置」
  • 配置立即生效

数据库管理

数据备份

  • 定期自动备份数据库
  • 支持手动备份

数据恢复

  • 从备份文件恢复数据

操作日志

  • 记录所有用户操作
  • 支持按时间和操作类型查询
  • 用于审计和追溯
