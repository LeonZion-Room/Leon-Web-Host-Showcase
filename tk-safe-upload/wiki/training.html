操作流程

1. 观看视频学习

操作步骤： 1. 点击课程卡片上的「开始学习」按钮 2. 视频自动开始播放 3. 可以使用播放器控制： - ⏯️ 播放/暂停 - ⏮️ 快退10秒 - ⏭️ 快进10秒 - 🔊 音量调节 - ⛶ 全屏播放 4. 系统自动记录观看进度 5. 视频播放到90%以上视为已完成视频部分

进度保存： - 系统每10秒自动保存一次进度 - 关闭页面后再次打开，自动从上次位置继续播放 - 进度条实时显示完成百分比

2. 打开文档学习

操作步骤： 1. 点击课程卡片上的「打开课件」按钮 2. 文档在新标签页中打开 3. 阅读完成后返回培训页面

3. 参加考试

触发条件： - 视频课程：视频播放进度达到90%以上 - 文档课程：点击「参加考试」按钮

考试流程： 1. 点击「参加考试」按钮 2. 弹出考试窗口，显示5道安全知识选择题 3. 每题4个选项，选择一个正确答案 4. 答完所有题目后点击「提交答卷」 5. 系统自动评分： - 60分及以上：通过考试 ✅ - 60分以下：未通过，可重新学习后再次考试

考试题目示例： | 题号 | 题目 | |------|------| | 1 | 灭火器使用时应站在哪个方向？ | | 2 | 高处作业的定义是指在几米及以上作业？ | | 3 | 发现火灾时应首先做什么？ | | 4 | 安全帽的作用是什么？ | | 5 | 触电急救的第一步是什么？ |

4. 查看学习进度

进度条颜色含义：

进度 颜色 说明
0% 灰色 未开始
1-89% 蓝色 学习中
90-100% 绿色 已完成

完成标记： - ✅ 已完成：视频看完+考试通过 - 📖 学习中：已开始但未完成 - 空白：未开始

PC后台 - 培训管理

管理员可以做什么？

1. 查看学习统计

页面顶部显示四项关键指标：

指标 说明
总课程数 已创建的课程数量
已完成人次 所有学员完成课程的总人次
总学习小时 所有学员累计学习时长
考试通过率 考试及格的比例

2. 管理课程库

新增课程： 1. 点击右上角「+ 新增课程」按钮 2. 填写课程信息： - 课程名称（必填） - 课程简介：课程描述说明 - 分类：课程类别 - 学时(分钟)：预计学习时长 - 视频链接：视频URL地址（可选） - 上传课件：支持视频/PDF/Word文件 3. 点击「保存」

查看课程： - 课程列表显示：名称、分类、文件类型、时长 - 点击「课件」链接可打开课程文件

删除课程： - 点击课程行内的「删除」按钮

3. 查看学习进度明细

详细的进度表格：

列名 说明
学员 学员姓名
课程 课程名称
签到时间 首次学习时间
学习时长 累计观看分钟数
进度 学习进度百分比+进度条
状态 已完成/学习中/未开始
考试分数 考试得分（如有）

颜色编码： - 🟢 绿色：已完成 - 🟡 黄色：学习中 - ⚪ 灰色：未开始

4. 导出学习数据

点击右上角「导出进度」按钮，下载Excel文件，包含： - 学员、课程、签到时间、学习时长、进度、是否完成、考试分数
