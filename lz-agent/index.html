LZ-Agent

机房自动化执行中心 · SSH 跨节点执行器 + 工单系统 + 定时巡检

部署于 L-Ubt Agent 节点的机房自动化执行中心，具备 SSH 跨节点执行器、工单系统与定时巡检三大能力，支持 SecOps 平台 AI 处置闭环，多模型协同（DeepSeek 文本 + 豆包视觉）驱动自主循环引擎。
