Features

面向 数据引擎 打造的核心能力

不只是一个静态文件托管，更是一套以内核引擎为驱动的项目数据交换与集成管理平台。

📦

静态站点托管

单文件 / 多页 HTML / SPA 站点一键托管到 /s/<name>/，即传即用无需构建。

  • 支持多文件目录结构
  • 自动识别 MIME 与字符集
  • 支持自定义 404 页面
📖

说明书 Wiki 站

每个项目自动获得 /w/<name>/，Markdown 编写、网页登录编辑、全文搜索。

  • 支持 Markdown 实时预览
  • 数据引擎 API 自动同步文档
  • 全文检索 + 历史快照
🕰️

Git 式版本管理

每次写入自动生成快照提交，最多保留 50 版历史，支持任意版本一键回滚。

  • 快照时间线可视化
  • 差异对比 / 单文件回滚
  • 提交信息可自定义
🖼️

图床服务

图片上传即时外链，配合站点素材统一管理，支持格式转换与 PDF 导出。

  • 拖拽 / 粘贴上传
  • 智能压缩 + 分屏切片
  • 支持 PDF / 长图导出
🔑

数据引擎 API

项目级 Token 读写接口，丰富的 RESTful + WebHook + WebSocket 接口支持跨平台集成与数据互通。

  • RESTful + MCP 协议双适配
  • Bearer Token / 项目级权限
  • OpenAPI 文档自动生成
🏷️

集成管理项目

首页按业务分组聚合展示，自定义图标与颜色，支持「未分组」兜底，统一纳管多平台项目。

  • 分组 Tab 快速筛选
  • 多平台项目统一汇聚
  • 支持后台动态管理
🧠

内核引擎

自研项目托管内核：存储引擎 / 调度引擎 / 集成引擎三大内核并行，毫秒级响应与高并发支撑。

  • 存储引擎：JSON 文件 + 快照分层
  • 调度引擎：异步任务 / 队列管理
  • 集成引擎：多平台协议适配
🔄

数据管交换

统一数据管交换协议，与 MemKV 记忆库、Leon-Control 管控台、图床、控制系统等深度互通。

  • 跨平台双向数据交互
  • Webhook 事件回调
  • OpenAPI 多语言 SDK
