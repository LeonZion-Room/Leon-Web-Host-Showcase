内核驱动 · 数据管交换 · 丰富接口 · 集成管理项目

项目托管数据引擎：每个项目拥有独立展示站与说明书 Wiki 站，Git 式快照版本管理支持历史回滚，通过统一数据管交换协议与 MemKV 记忆库、Leon-Control 管控台、图床、控制系统等多平台数据互通。

Features

功能特性

以自研内核驱动的项目托管数据引擎，提供从存储到集成的完整能力。

📦

静态站点托管

/s/<项目>/ 一键托管单页或多页 HTML 站点，即传即用

📖

说明书 Wiki 站

/w/<项目>/ 提供 Markdown Wiki，登录网页编辑、全文搜索

🕰️

Git 式版本管理

每次写入生成快照提交，最多保留 50 版历史，随时一键回滚

🖼️

图床服务

图片上传外链直用，配合站点素材统一管理

🧠

数据引擎 API

项目级 Token 读写接口，丰富 RESTful / WebHook / WebSocket 接口支持跨平台集成

🏷️

集成管理

首页按「AI 智能 / 平台开发 / 安全运维 / 基础服务」分组聚合展示，统一纳管多平台项目

⚙️

自研内核

存储引擎 / 调度引擎 / 集成引擎三大内核并行，毫秒级响应与高并发支撑

🔄

数据管交换

统一数据管交换协议，与 MemKV 记忆库、Leon-Control 管控台等多平台数据双向互通
