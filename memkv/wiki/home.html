MemKV · 打通 AI 与人的人性化记忆基础设施

产品定位

MemKV 不只是一个 AI 知识库，更是一座打通 AI 与人的人性化记忆桥梁。它让 AI 像人一样拥有可被任意设备、任意模型、任何场景共享的长期记忆层，同时让人类也能像浏览普通笔记一样读、写、批注、分享这些记忆。

核心理念 · 打通 AI 与人

AI 视角：可被调用的持久化记忆

  • 跨会话记忆：每次新会话开始，AI 自动 search 加载历史偏好，告别"金鱼脑"
  • 跨设备同步：一个 Token，所有设备、所有模型、所有 Agent 共享同一份记忆
  • 结构化输出：纯 JSON / Markdown 直接喂给 LLM，无需预处理
  • 可解释检索：关键词 + References 引用，AI 知道每条记忆的来龙去脉
  • 自动上下文：会话开始即自动拉取相关 Skill / SOP / 偏好，AI 立刻进入工作状态

人的视角：人性化交互界面

  • 像写笔记一样管理：Markdown 编辑器，所见即所得
  • 像查资料一样查阅：左侧目录 + 全文搜索 + 标签云
  • 像分享文档一样分享：公开链接、二维码、嵌入外部网页
  • 像备份文件一样备份：JSON / MD / HTML / PDF 四种格式一键导出
  • 像整理文件夹一样整理：三级树形结构，分类、标签、引用一目了然

双向桥梁 · 人机协作

场景 AI 怎么用 人怎么用
新增记忆 AI 通过 API 写入条目，自动分类、添加标签 人通过 Web 编辑器撰写，AI 后续补充
更新记忆 AI 根据上下文自动 update 条目内容 人修订后 AI 自动感知变更
查询记忆 AI 启动时 search 拉取相关上下文 人通过搜索框查阅具体内容
分享记忆 AI 生成公开 URL / 二维码 人扫码或复制链接分享给同事
备份记忆 AI 定时快照 + Git 增量同步 人一键导出 JSON / PDF 归档

三级树形结构

项目 (Project)
  └─ 分组 (Group)
       └─ 条目 (Item)
            └─ 引用 (References) → 其他条目
  • 项目：独立知识空间，如 Leon-Note、开发相关、个人文档
  • 分组：项目内的分类，如 【项目】汇总、【投控】信息（设备）
  • 条目：最小知识单元，每个条目都有 summary 摘要 + content 正文 + references 关联
  • 引用：条目间通过 <a class="wl wl-missing" href="wiki/wikilink.html">wikilink</a> 或 references 字段相互关联，形成知识图谱

API 一览

方法 路径 说明
GET /api/v1/memory/index 获取完整记忆树
GET /api/v1/search?keyword=词 关键词全文搜索
GET /api/v1/item/content?project_name=..&group_name=..&item_name=.. 读取条目正文
POST /api/v1/item/content 创建/更新条目
POST /api/v1/erase 删除条目（公网接口，避开 WAF 拦截）
GET /api/v1/share/qrcode?url=... 生成二维码
GET /api/v1/export?format=md 导出 Markdown

人性化设计

  • 双视角数据模型：AI 看到的是结构化 JSON，人类看到的是可读 Markdown
  • 自然语言写备注：条目支持 <a class="wl wl-missing" href="wiki/wikilink.html">wikilink</a> 双链语法，像写笔记一样
  • AI 补充 + 人类修订：AI 写入后人类可继续修订，反之亦然
  • 草稿与正式版分离：每个条目有 summary 简述 + content 正文，新人先看 summary
  • 跨模型兼容：不绑定任何特定 LLM，OpenAI / DeepSeek / Claude / 自研模型通吃
  • 零冷启动：无需 Embedding 模型，无需 GPU，开箱即用
