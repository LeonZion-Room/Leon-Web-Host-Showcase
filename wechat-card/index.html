Features

功能特性

围绕实际业务场景打磨的核心能力：模块化组件、所见即所得编辑、分享卡片生成。

👤

电子名片 H5

手机端优先的精致名片页面，vCard 一键存入通讯录，加载迅速、样式现代。

🧩

组件化架构

多标签嵌套组件支持（联系/标题/文本/图片/视频/PDF/标签页），模块参数统一清理管理。

🖱️

所见即所得编辑

点击资源直接弹窗上传替换，四段式分组重组编辑界面，?dev=1 开发者预览模式。

📲

vCard 通讯录

访客一键将名片信息存入手机通讯录，符合 vCard 3.0 标准规范。

🖼️

分享卡片生成

微信分享自动抓取 OG 标签，卡片标题/描述/缩略图全部可自定义。

🔄

资源热替换

在线上传图片/视频/PDF 即时替换原引用，开发态实时生效。

🔐

Token 鉴权

编辑后台与开发预览通过 wswwsw1234 Token 保护，公开分享链接可选。

🗂️

分组管理

支持创建/复制/移动分组，按业务场景组织名片（个人版 / 文旅版 / 投控版）。

🔍

JSAPI 签名

内置微信 JS-SDK 签名接口，/api/wechat-sign 即取即用。
