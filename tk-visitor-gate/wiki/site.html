站点设置

管理员登录 → 管理后台 →「站点设置」标签页。

可配置项

首页自定义卡片

在首页展示功能入口卡片（图标 + 标题 + 描述 + 链接）。

  • 默认卡片：访客预约、员工审批、管理后台
  • 支持添加、修改、删除自定义卡片
  • 每张卡片支持自定义标题、图标、Logo、跳转链接、描述

页面标题

配置 说明
网站标题 显示在导航栏
浏览器标题 显示在浏览器标签页

主题配色

支持 5 种配色方案：

配色 主色调
default（默认） 深蓝
green 深绿
red 深红
purple 紫
orange 橙

微信分享卡片（OG 标签）

自定义分享到微信时显示的卡片样式：

  • 分享卡片标题
  • 分享卡片描述
  • 分享卡片图片（建议正方形）

底部页脚

  • 多列自定义页脚（联系方式、链接）
  • 版权信息
  • 联系人、电话、微信、邮箱

公告栏

  • 支持 Markdown 格式的公告内容
  • 可控制公告是否在前台展示
  • 记录最后更新人和更新时间

操作步骤

  1. 登录后进「管理后台」→ 站点设置标签页
  2. 修改需要的配置项
  3. 点击「保存」
  4. 前台立即生效（无需重启）
