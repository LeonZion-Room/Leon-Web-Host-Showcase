访客预约

访客无需登录，直接访问首页 → 点击「访客预约」卡片进入预约页。

填写预约信息

打开系统首页 http://119.145.17.34:5102 → 点击「访客预约」卡片（路径 /visitor）。

字段 说明 必填 校验规则
访客姓名 来访人员的真实姓名 是 —
访客手机号 用于接收通行链接 是 11 位手机号格式
来访开始时间 什么时候来 是 日期+时间
来访结束时间 什么时候走 是 不能早于开始时间；仅选日期时自动算到 23:59:59
来访门禁 要进的门 是 可多选，至少选一种
经办人 接待你的公司员工 是 只能从有审批权的管理员里选
来访事由 比如商务拜访、开会 否 —

选择门禁点位

页面默认先列出人脸设备（刷脸闸机）。

  • 点击「＋显示普通门禁设备」会展开全部普通门锁点位
  • 人脸闸机与普通门锁至少选择一种，也可以都选
  • 门禁列表支持按名称搜索过滤

提示：勾选框变蓝表示已选中，至少有一个勾选才能提交。

提交后

确认信息无误 → 点击「提交预约」按钮。

系统生成一条预约记录，状态为「待审批」。经办人会收到审批通知。

flowchart LR
    A[提交预约] --> B[状态: 待审批]
    B --> C[经办人审批]
    C -->|通过| D[分配账户+授权+二维码]
    C -->|拒绝| E[状态: 已拒绝]

字段校验

系统会自动校验以下内容，不通过时会阻止提交：

  • 手机号格式（必须 11 位数字）
  • 结束时间不能早于开始时间
  • 门禁点位至少选一种
  • 经办人必须选择

注意事项

  • 预约提交后不能修改，如需更改请让经办人拒绝后重新预约
  • 经办人下拉框只显示已启用且有审批权的管理员
  • 预约页的设备显示可在管理后台配置隐藏
