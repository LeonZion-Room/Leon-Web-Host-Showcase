onlyoffice 使用说明书

欢迎来到本项目的在线说明书（Wiki），与展示站相互独立、专门用于维护文档。

如何使用

  • 左侧目录浏览所有页面，顶部搜索框支持标题过滤与全文搜索
  • 点击右上角「✏️ 编辑」，登录后即可用 Markdown 修改当前页
  • 「🕘 历史」可查看本页修改记录，并一键恢复任意旧版本
  • 每次保存自动生成版本快照，可随时回滚

AI 接口维护

本项目说明书开放 REST API，AI Agent 可使用项目 Token 自动更新内容：

GET  /api/projects/onlyoffice/wiki/tree          # 页面目录
GET  /api/projects/onlyoffice/wiki/page?path=home&raw=1
POST /api/projects/onlyoffice/wiki/page          # 创建/更新页面

完整接口说明见项目主页「📖 AI 接入文档」。
