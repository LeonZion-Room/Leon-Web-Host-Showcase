Leon Infra · 基础设施数据引擎

产品定位

Leon Infra 是一款面向基础设施的数据引擎平台，具备内核级的设备监控、公网接入、虚拟化集群管理与 HTTPS 网关能力。平台采用统一数据管交换协议，支持与 MemKV 记忆库、Leon-Control 控制台、公网接入体系等多个系统的双向数据交互，通过丰富的 REST API 与 Webhook 接口，实现跨平台的数据无缝流转。

架构优势

内核引擎

  • 设备发现引擎：基于内存库自动发现内网设备，支持物理机、虚拟机、容器多形态探测
  • 实时监控引擎：CPU/内存/磁盘/GPU/负载等指标的毫秒级采集与聚合
  • 公网端口引擎：EG3220 NAT 规则、nginx 四层透传、FRP 穿透三引擎并行管理，28 个公网端口精细化治理
  • 虚拟化引擎：4 节点 ESXi 集群，100TB 共享存储，16+ 虚拟机资源编排
  • 网关引擎：Caddy 反代网关，单一入口多路径路由，TLS 证书自动续期

数据管交换

  • MemKV 联动：设备实时状态写入记忆库，实现跨 Agent 的上下文共享
  • Leon-Control 对接：监控数据推送至脚本管理 + SEO 控制台，统一纳管 20+ 服务
  • 公网接入协同：端口映射、防火墙策略、WAF 规则通过 API 动态下发
  • ESXi 集群集成：虚拟机生命周期管理、资源调度、快照备份全自动化

接口丰富

接口类型 说明
REST API 设备状态、端口映射、虚拟机信息、网关路由的增删改查
WebSocket 实时监控数据流推送，毫秒级状态更新
Webhook 告警事件回调，支持自定义动作触发
OpenAPI 标准化接口文档，支持多语言 SDK 对接

服务组件

1. 设备管理面板 (devices)

  • 描述：内核级设备自动发现 · 实时状态监测
  • 访问：http://192.168.11.70:5071
  • 引擎能力：物理机 / Linux VM / Windows VM 分类探测，CPU / 内存 / 磁盘 / GPU / Load 毫秒采集，SSH 快捷指令下发

2. 公网接入体系 (public-access)

  • 描述：EG3220 NAT + Safe nginx 透传 + FRP 穿透 · 公网端口数据引擎
  • 访问：http://119.145.17.34:5000/
  • 引擎能力：98 条 NAT 规则引擎 / 28 个公网端口管控 / 3 层接入链路编排（公网 → EG3220 NAT → Safe 透传 → 内网节点）

3. ESXi 虚拟化集群 (esxi-cluster)

  • 描述：4 节点 ESXi 集群 · 100TB 共享存储 · 16+ 虚拟机资源池
  • 访问：192.168.11.51 – 54（vmesxi01–04）
  • 引擎能力：四台 ESXi 主机并行算力池 / 100TB 共享存储引擎 / 承载 TK-Server / L-Ubt 系列 / Leon-Docker 等 16+ 个生产虚拟机

4. Caddy 反代网关 (caddy-gateway)

  • 描述：基于 Caddy 的 HTTPS 反代网关 · 数据路由引擎
  • 访问：https://leyon.top:8443/
  • 引擎能力：leyon.top:8443 单一入口 / 按 URL 路径智能路由 / TLS 证书自动续期管理 / HTTP/3 加速
